# Billion Vibe Records website

## Add gallery photos

On GitHub, open the `main` branch and use **Add file → Upload files** at the
repository root, next to `index.html`. Give each image a unique name starting
with lowercase `gallery-`, such as `gallery-10.jpg`. Use JPG, JPEG, PNG, WebP,
AVIF, or GIF. The extension can be uppercase or lowercase.

Commit the uploads to `main`. The existing GitHub Pages Jekyll build finds
these files and adds them to the Gallery in filename order. No HTML edits or
separate build steps are needed. Check the Pages deployment under **Actions**.

## Replace the logo

Replace `logo-2.png` in the repository root with the new PNG, using that exact
filename. Commit it to `main`. The header, footer, and browser icon all use
that file.
